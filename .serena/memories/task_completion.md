# Task Completion Checklist

- Run git inspection commands as needed to review the final diff.
- Because the repo has no local build, test, lint, or formatter configuration, validation is primarily manual in Transport Fever 2.
- For settings and localization changes, verify labels and tooltips in the mod options UI.
- For name-data changes, verify Indonesian town, street, and person names appear in map setup and person generation.
- For vehicle filter or terrain generator changes, reload the mod and smoke-test the behavior in-game.
- When changing runtime paths, filenames, or base-game asset references, cross-check the sibling base_game workspace first.
